# 故障排查

| 现象 | 检查 |
| --- | --- |
| 页面无法启动 | 先运行 `scripts/setup.ps1` 构建前端并准备后端依赖，确认本机端口 7866 可绑定。 |
| CUDA 或 BF16 不可用 | 运行 `scripts/doctor.ps1`，检查解释器、CUDA 驱动、可用显存和实际张量运算。RIFT 要求 Python 3.11+。 |
| FFmpeg 可运行但 TorchCodec 无法读取 | Windows 还需要兼容 FFmpeg 共享 DLL。程序会检查 FFmpeg 同目录和相邻项目已有的共享库。可用 `TIMBREFORGE_FFMPEG_DLL_DIR` 指定 DLL 目录。 |
| 显存不足 | 查看 `nvidia-smi` 的当前占用。释放其他应用占用再试。WebUI 保留所选训练 batch 和采样步数。 |
| 资产下载失败 | 保留 `.part` 后重试。若已下载文件的哈希与锁不匹配，移开损坏文件后再下载。Hugging Face 不通时可在 `assets.ps1 -HuggingFace` 指定镜像，所有文件仍按锁定哈希校验。 |
| 无法开始训练 | 检查训练划分至少有一个完整 batch，验证划分非空，特征文件和底模都已准备。 |
| 导出失败或磁盘满 | 先清出空间。存在已落盘导出快照时可从训练任务的导出列表重试。恢复点索引仅列出已提交的文件。 |
| 外部模型无法导入 | 需要 RIFT V3 权重、合法的 speaker 映射和匹配的结构。导入对文件执行 CPU 严格加载。 |
| 网易云会话无效 | 运行相邻项目已有的登录入口，在同一 Windows 用户下启动 TimbreForge。检查路径覆盖和账号权限。 |
| 源音源 403 或仅有试听 | 桥接会有界重新解析 403。若该版本仍不可用，重新搜索并手动选择其他有完整音源的版本。 |
| 翻唱中断 | 等该任务状态变为失败或中断后重试。任务选定的模型、歌 ID 与处理参数保持冻结。 |
| 旧临时音频仍占磁盘 | 释放 Windows 播放句柄。清理任务会在有限次数内重试，旧链接已经失效。 |
