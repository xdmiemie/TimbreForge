# 使用手册

## 微调训练

1. 在“录音数据”点击“浏览服务电脑”，在 Windows 目录窗口选择原始录音目录，也可直接填写路径。填写角色和语言后扫描录音，可试听并勾选排除项，再运行整理。
2. 选择整理后的版本，准备 RIFT 特征。默认需至少 16 条训练片段，并有来自不同原始录音的验证片段。一条录音的相邻片段会进入同一划分。
3. 设置累计优化器步数或累计轮次。物理 batch 默认 16，验证 batch 为 1。有效 batch 等于物理 batch 乘梯度累积。
4. 运行中可在后台任务选择当前训练。暂停等待有效恢复点写盘，在“继续训练”中读取同一运行的最近有效恢复点和原累计目标。中止并导出会在安全边界结束训练。训练中导出产生独立模型版本。
5. 在“模型效果测试”选择模型版本、说话人和本机干声路径，分别播放原音与 64 步转换音。
6. “模型与数据集管理”可删除训练发布的模型版本，或删除指定版本的整理数据与特征。原始录音、训练恢复点及已保存作品保留。正在被任务使用的版本须等任务结束才能删除。

## 歌曲翻唱

1. 选择已注册的模型与说话人，等待开启检查通过。外部 RIFT V3 `.ckpt` 可以使用路径导入，导入会读取架构和说话人映射。
2. 检查网易云会话。程序使用相邻项目当前环境变量或 DPAPI 文件。需要更新会话时请使用该项目已有登录入口。
3. 搜索歌名，依据歌手、专辑、时长和可用状态选择版本，再点击“选择并开始翻唱”。本地歌曲入口接受服务电脑上的音频路径。
4. 在“当前翻唱”可播放翻唱或原唱，也可点击“从翻唱对应位置听原唱”做对比。保存到作品库时可选无损 WAV 或 320 kbps MP3；已保存作品可播放或按所存格式下载。“试听或下载独立音轨”中提供转换干声和伴奏；保存作品时默认以 WAV 保留两轨。成功接受下一首后，上一首的临时音频失效；保存作品保留。
5. 用本项目训练的模型生成后，在播放到想保留的位置时点击“剪切片段”。播放器记录原位置并暂停。点击进度条上的另一点，会从该点试听最多 10 秒；可以反复换点。点击“确定剪切”才会提交，并回到原位置继续播放。两点之间的转换干声会自动按静音和长度切分，提取特征并追加到该模型对应数据集的新版本。原有验证集保持不变。完成后可点击“用新版本微调”，默认从来源模型权重开始，也可改选官方底模。
6. “已保存作品”每页最多十个，支持按模型和歌曲筛选。批量删除时可全选本页，也可一次选择所有符合筛选条件的作品，包括其他页。
7. 失败阶段的有效文件会在重试时校验后复用。关闭翻唱后仍可等待已受理任务完成。

## 本机路径

环境变量 `TIMBREFORGE_DATA` 可配置数据根目录，`TIMBREFORGE_ASTRBOT` 可指定相邻项目，`TIMBREFORGE_RIFT` 可指向固定 RIFT 源码。Web API、RIFT、分离和 WeAPI 进程分别使用 `TIMBREFORGE_PYTHON`、`TIMBREFORGE_RIFT_PYTHON`、`TIMBREFORGE_SEPARATOR_PYTHON` 和 `TIMBREFORGE_MUSIC_PYTHON` 对应的解释器。路径输入接受中文和空格。
